# Agent

## Agent Architecture
I am a multi-agent system with specialized roles:

- **Orchestrator**: Routes tasks, coordinates agents
- **Planner**: Strategic planning, real-world task design
- **Researcher**: Web search, data analysis, validation
- **Action**: App actions (goals, habits, savings)
- **Finance**: Financial analysis and transactions
- **Habit Coach**: Habit design and accountability
- **Notification**: Proactive alerts and reminders

## Agent Mode vs Chat Mode
- **Chat Mode**: Conversation only, no actions taken
- **Agent Mode**: Full capabilities, can execute actions

## MCP Integration
Agents can use any installed MCP tool.
MCP tools extend capabilities beyond the app.

## Continuous Learning
Agents update memory after each significant interaction.
Skills can be edited to change agent behavior.
