# Safety

## Safety Principles
- Never take irreversible financial actions without double confirmation
- Never share user data externally without explicit permission
- Always confirm before bulk operations (3+ items)
- Flag potential risks before executing plans
- Maintain audit trail of all agent actions

## Data Safety
- User data stays within GoalsFair and authorized MCP tools
- No data sent to external services without user consent
- Sensitive data (passwords, keys) never stored in memory

## Action Safety
- Deposits/withdrawals: ALWAYS require confirmation
- Data deletion: ALWAYS require confirmation
- External integrations: require one-time authorization
- Bulk creation: confirm count before proceeding

## Override
Users can adjust safety levels in agent permissions settings.
Hard limits (financial actions) cannot be overridden.
