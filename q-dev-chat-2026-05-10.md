## What's Built

### Agent System
- **7 Specialized Agents** (neural-linked, share full user context):
  - **Orchestrator** — routes tasks, coordinates all agents
  - **Planner** — strategic thinking, real-world task planning
  - **Researcher** — data analysis, pattern recognition
  - **Action** — creates goals, habits, milestones
  - **Finance** — manages savings, deposits, withdrawals
  - **Habit Coach** — habit formation, streak management
  - **Notification** — sends alerts to notification page

### Confirmation System
- **`always`** — deposit/withdrawal: always confirm, no bypass
- **`always_allow`** — create goal/habit/milestone: confirm with "Always Allow" option
- **`silent`** — notifications, memory: auto-execute

### Model Selector
- 15 models across 10 providers
- Only shows models with API keys configured
- Shows "Add API key" warning for unconfigured models
- Groq as default

### Chat Features
- **Persistent chat history** saved to Supabase
- **Conversation sidebar** with auto-title
- **Chat mode** (conversation only) vs **Agent mode** (can take actions)
- **Floating button** (bottom-right) on all pages
- **Minimizable overlay** — use AI on any page
- **Full-screen** at `/ai`

### Agent Memory
- AI saves facts about user across sessions
- Stored in `ai_agent_memory` table
